# AAAI-27 upload set

Upload the four files in this directory to the matching OpenReview fields:

- `Reproducibility_Checklist.pdf` — required standalone answered checklist.
- `Technical_Supplement.pdf` — anonymous technical details; below 10 MB.
- `Media_Supplement.zip` — anonymous figures and manifest; below 50 MB.
